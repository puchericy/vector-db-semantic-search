# Семантичний пошук у навчально-методичних матеріалах з баз даних (векторна БД Chroma)

Курсова робота. Корпус: статті Вікіпедії (uk/en) з категорії «Бази даних», 72 пари статей.
Модель ембедингів: `intfloat/multilingual-e5-small` (384 вимірів). Векторна БД: Chroma 1.5.9 (HNSW, cosine).

## Середовище
- Windows, Python 3.12.1, CPU (Intel, 8 логічних ядер), 16 ГБ ОЗП, без відеокарти.
- Залежності: `py -m pip install -r requirements.txt`.

## Порядок запуску (усі команди з папки проєкту)
| Крок | Команда | Результат |
|---|---|---|
| 1. Збір даних | `py collect_uk.py` | `articles_uk_en.json` (знімок корпусу від 30.10.2026) |
| 2. Фрагменти | `py chunk.py` | `chunks.json` (ліміт 800 знаків, мінімум 100; 5 фрагментів довші, найдовший 1209) |
| 3. Ембединги | `py embed.py` | `embeddings.npy` (близько 150 с на CPU) |
| 4. Оцінка на основному наборі | `py eval_queries.py` | `results_per_query.csv` |
| 5. Порівняння варіантів V1-V4 | `py eval_variants.py` | `results_variants_queries.csv` |
| 6. Контрольний набір | `py eval_variants.py queries_holdout.json` | `results_variants_queries_holdout.csv` |
| 7. Перевірка запитів | `py check_overlap.py queries_holdout.json` | збіг слів запиту з текстом статті |
| 8. Аналіз помилок | `py error_analysis.py` | `error_analysis.txt` |
| 9. Векторна БД | `py build_chroma.py` | `chroma_db/`, `chroma_report.txt` |
| 10. Швидкість HNSW | `py bench_ann.py 10000 100000` | `bench_report.txt`, `bench_results.csv` |
| 11. Прикладні запити Д1-Д7 | `py demo_search.py` | `demo_report.txt` (потрібна база з кроку 9) |
| 12. Схема колекції (перевірка) | `py schema_chroma.py` | створює порожню демонстраційну колекцію й перевіряє схему запису |

Додатково збережено перший запуск кроку 10 з обсягами 10 000, 100 000 і 300 000: `bench_report_run1.txt`, `bench_results_run1.csv`. Допоміжні скрипти й старі файли лежать у підпапці `допоміжні` і для відтворення не потрібні.


## Дані й відтворюваність
- Вікіпедія змінюється, тому збір даних (крок 1) не відтворюється дослівно. Для відтворення результатів
  використовуйте збережений `articles_uk_en.json`.
- Тексти Вікіпедії поширюються за ліцензією CC BY-SA; потрібна атрибуція.
- Контрольний набір запитів: `queries.json` (основний, 57), `queries_holdout.json` (контрольний, 25).
  Поля: `relevant` (основні відповіді, номери статей), `partial` (часткові).
- Випадкові процеси фіксовано (`seed`), але час виконання залежить від комп'ютера.

## Обмеження
- Дані для вимірювання швидкості згенеровані (реальні ембединги + шум), не реальні тексти.
- Кількість запитів невелика (57 і 25), складних запитів мало.
- Англомовні версії статей 59 і 90 описують інші теми, ніж українські.
